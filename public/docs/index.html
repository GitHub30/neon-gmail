Neon Gmail 公式ドキュメント & FAQ

ブラウザで動くモダンな Gmail 互換 Web メールクライアント（IMAP/SMTP プロキシ・PWA・ライト/ダーク・複数アカウント切替対応）。

1. Cloudflare Workers プロキシのデプロイ

Cloudflare Workers の cloudflare:sockets を利用し、TLS/STARTTLS による IMAP・SMTP 通信を CORS 対応（Access-Control-Allow-Origin: *）REST API として提供します。

git clone https://github.com/GitHub30/neon-gmail.git
cd neon-gmail/workers/mail-proxy
npm install
npx wrangler login
npx wrangler deploy

発行された https://neon-gmail-proxy.<subdomain>.workers.dev をログインダイアログの「プロキシ URL」に入力してください。

2. proxy.php での接続（共有レンタルサーバー対応）

PHP 8.0 以上のサーバーへ proxy.php を1ファイル設置するだけで利用できます（php-imap・mbstring 拡張不要）。

curl -i https://your-domain.example/proxy.php?action=health

3. Node.js スタンドアロンプロキシ（proxy-node.mjs）

VPS や Docker 環境では Node.js 20+ のみで起動できます。

HOST=0.0.0.0 PORT=8787 node proxy-node.mjs

4. よくある質問（FAQ）

プロキシ URL を設定しなくても使えますか？
はい。プロキシ URL はオプションです。空欄のままアカウントを追加するとブラウザ内ローカルモードで下書き・作成・ラベル管理などが利用でき、後からいつでもプロキシ URL を設定して IMAP/SMTP 送受信へ切り替えられます。
アカウント情報はどこに保存されますか？
メールアドレス・パスワード・プロキシ URL・設定はブラウザの localStorage に保存されます。共有端末ではアプリパスワードのご利用とログアウトを推奨します。
複数アカウントの切り替え方法は？
画面右上のアカウントアイコンをクリックするとドロップダウンが開き、登録済みアカウントをワンクリックで切り替えられます。
